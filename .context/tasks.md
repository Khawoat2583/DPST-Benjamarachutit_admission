ระบบลงทะเบียนออนไลน์สำหรับนักเรียนเพื่อกรอกข้อมูล ประวัติ ผลการเรียน และอัปโหลดเอกสารหลักฐาน

- [x] **หน้าต่างล็อกอิน / ตรวจสอบสิทธิ์ผู้สมัคร:** 
  - [x] ล็อกอินเข้าสู่ระบบโดยใช้เลขประจำตัวประชาชน 13 หลัก และลำดับตามประกาศผลสอบรอบแรก
- [x] **การบันทึกข้อมูลส่วนบุคคลและข้อมูลติดต่อ:**
  - [x] ฟอร์มกรอกคำนำหน้านาม, ชื่อ-นามสกุล, ที่อยู่ปัจจุบัน/ทะเบียนบ้าน, อีเมล, หมายเลขโทรศัพท์ และเบอร์โทรศัพท์ผู้ปกครอง
  - [x] ระบบตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลัก (Checksum Validation)
- [x] **การบันทึกผลการเรียน 5 ภาคเรียน (ม.1 - ม.3 เทอม 1):**
  - [x] ช่องสำหรับกรอก GPAX รวม 5 ภาคเรียน
  - [x] ตารางกรอกผลการเรียนแยกวิชาสะสมเฉพาะรายวิชาพื้นฐาน (คณิตศาสตร์, วิทยาศาสตร์, อังกฤษ)

- [x] **ระบบประเมินคุณสมบัติขั้นต่ำอัตโนมัติ (Automatic Qualification Check):**
  - [x] ตรวจสอบคุณสมบัติขั้นต่ำเรียลไทม์ระหว่างกรอกข้อมูล (GPAX >= 3.00, คณิต >= 3.00, วิทย์ >= 3.00, อังกฤษ >= 2.75) พร้อมสัญลักษณ์สีแดง/เขียวและอนิเมชันแจ้งเตือน
- [x] **การอัปโหลดไฟล์หลักฐานประกอบการรับสมัคร:**
  - [x] รองรับการอัปโหลดรูปถ่ายสีหน้าตรงชุดนักเรียน, เอกสารระเบียน ปพ.1 ด้านหน้าและด้านหลัง, และสำเนาบัตรประชาชน
- [x] **ระบบความปลอดภัยของใบสมัครและการกดยอมรับปฏิญาณตน:**
  - [x] แสดงคำรับรองและปฏิญาณตนตามที่กฎหมายกำหนดก่อนกดยืนยันส่งใบสมัคร
  - [x] ระบบบันทึกใบสมัครชั่วคราว (Draft) และปุ่มยืนยันส่งใบสมัครเข้าระบบ (Submitted)
  - [x] ฟังก์ชันการล็อกการส่งหรือแก้ไขข้อมูลใบสมัครฝั่งผู้สมัครหลังปิดรับสมัคร

## 💻 2. แผงควบคุมและระบบจัดการสำหรับเจ้าหน้าที่ (Admin Review Portal)
หน้าหลักสำหรับการตรวจสอบเอกสารข้อมูล ตรวจทาน และอนุมัติใบสมัครของผู้สมัครแบบประสานความร่วมมือ (Human-in-the-Loop)

- [x] **โครงสร้างแดชบอร์ดเจ้าหน้าที่ (Admin Dashboard & Main Layout):**
  - [x] ออกแบบเส้นทาง URL `/admin` และระบบกรองผู้ใช้งานจำกัดเฉพาะสิทธิ์เจ้าหน้าที่
  - [x] หน้ารวมใบสมัครทั้งหมด แสดงสถานะใบสมัครแบบ Real-time และระบบแบ่งประเภทสถานะ
  - [x] ตัวกรองและค้นหาใบสมัคร เช่น ค้นหาจากชื่อ, นามสกุล หรือเลขบัตรประชาชน
- [x] **ระบบตรวจสอบเอกสารแบบคู่ขนาน (Side-by-Side Review Canvas):**
  - [x] อินเทอร์เฟซแบบแบ่งครึ่งหน้าจอ (Split Panel) ข้างหนึ่งแสดงข้อมูลและเกรดผู้สมัคร อีกข้างหนึ่งแสดงเอกสารหลักฐานอัปโหลด
  - [x] กล่องโหลดภาพ ปพ.1 ดึงภาพระเบียน **"ด้านหน้าและด้านหลังมาแสดงพร้อมกันในหน้าจอเดียว"** เพื่อความสะดวกในการตรวจทานเกรดและ GPAX
  - [x] ฟังก์ชันในการซูม (Zoom) และหมุน (Rotate) ภาพเอกสาร ปพ.1 และบัตรประชาชน
- [x] **สิทธิ์การปรับปรุงแก้ไขข้อมูลตรงโดยเจ้าหน้าที่ (Administrative Editing Rights):**
  - [x] ระบบให้สิทธิ์เจ้าหน้าที่กรอกแก้ไขเกรดรายวิชาและหน่วยกิตเพื่อความถูกต้องตรงตามเอกสาร ปพ.1 ได้ทันที
- [x] **การปรับสถานะใบสมัครแบบ Human-in-the-Loop:**
  - [x] ปุ่มสั่งการ **อนุมัติใบสมัคร (Approve)** (ซ่อน/ปิดเมื่อสถานะเป็น Approved)
  - [x] ปุ่มสั่งการ **ส่งกลับเพื่อแก้ไข (Reject)** พร้อมระบุเหตุผลในการส่งกลับแบบละเอียด (ซ่อน/ปิดเมื่อสถานะเป็น Rejected)
- [ ] **การควบคุมความปลอดภัยของบัญชีและประวัติการใช้งาน (Remaining Features):**
  - [ ] **ระบบบันทึกประวัติการเข้าใช้งานและแก้ไข (Audit Logs):** บันทึกประวัติการแก้ไขข้อมูลส่วนบุคคลและการเปลี่ยนสถานะใบสมัครลงในฐานข้อมูลอย่างถาวร (บันทึก Admin ID, การแก้ไข, วันที่เวลา และ IP Address)
  - [ ] **Brute Force Protection:** ระบบ Rate Limiting ที่หน้าล็อกอินเจ้าหน้าที่
  - [ ] **Dynamic Session Inactivity Timeout:** ระบบตรวจสอบและล้างเซสชันเมื่อไม่มีการโต้ตอบภายใน 1 ชั่วโมง (PDPA Compliant)
  - [ ] **Strict Session Cookie Hardening:** ปรับแต่งเซสชันคุกกี้ของเจ้าหน้าที่ให้เป็น `SameSite="Strict"` และจำกัดเฉพาะ Path `/admin`

- [x] **หน้าต่างนำเข้าไฟล์และ API การนำเข้าคะแนน (Import UI & Endpoint):**
  - [x] หน้าเว็บสำหรับลากและวางไฟล์อัปโหลด `.xlsx` และฟังก์ชันการอ่านข้อมูล Excel บนเซิร์ฟเวอร์
- [x] **ระบบตรวจสอบความถูกต้องไฟล์ล่วงหน้า (Preflight Validation):**

- [x] **การเชื่อมโยงคะแนนประมวลผล (External Data Matching):**

ขั้นตอน Manual Workflow และเกณฑ์จัดอันดับหลังปิดรับสมัครโดยควบคุมโดยดุลยพินิจของเจ้าหน้าที่

- [x] **แผงควบคุมสถานะรับสมัคร (System Workflow Control Panel):**
  - [x] **ปุ่มปิดรับสมัคร (Close Application Window):** สั่งบล็อกการลงทะเบียนใหม่และล็อกการส่งหรือแก้ไขข้อมูลใบสมัครฝั่งผู้สมัคร
  - [x] **ปุ่ม Lock Edit:** ยืนยันการล็อกการแก้ไขข้อมูลผู้สมัครทั้งหมดหลังเจ้าหน้าที่ตรวจสอบเอกสารเสร็จสมบูรณ์
- [x] **ประมวลผลการจัดลำดับการคัดเลือก (Run Ranking Process):**
  - [x] พัฒนา API เชื่อมต่อกับ Ranking engine เพื่อประมวลผลและเก็บประวัติจัดอันดับแบบอย่างเป็นทางการ
  - [x] บันทึกค่าลำดับที่ของทุกคนลงฐานข้อมูล
  - [x] การคำนวณและประมวลผลจัดเรียงโดยใช้ค่าที่ปัดทศนิยมแล้ว
  - [x] **เกณฑ์ Tie-Breaking 8 ขั้นตอนอย่างเป็นทางการ:**
    1. คะแนนสอบคณิตศาสตร์รอบแรก
    2. คะแนนสอบวิทยาศาสตร์รอบแรก
    3. ผลการเรียนเฉลี่ยสะสมรายวิชาคณิตศาสตร์พื้นฐาน 5 ภาคเรียน
    4. ผลการเรียนเฉลี่ยสะสมรายวิชาวิทยาศาสตร์พื้นฐาน 5 ภาคเรียน
    5. ผลรวมเกรดเฉลี่ยสะสมคณิตศาสตร์และวิทยาศาสตร์พื้นฐาน 5 ภาคเรียน
    6. ผลการเรียนเฉลี่ยสะสมรายวิชาภาษาอังกฤษพื้นฐาน 5 ภาคเรียน
    7. เกรดเฉลี่ยสะสมรวมทุกกลุ่มสาระการเรียนรู้ (GPAX)
    8. ลำดับรายชื่อตามประกาศผลการสอบรอบแรก พสวท. (ลำดับดีกว่าได้อันดับที่สูงกว่า)

## 📤 5. การส่งออกรายงานผลการจัดอันดับ (Ranking Report Export)
ระบบสร้างและดาวน์โหลดรายงานกลับคืนให้ พสวท.

- [x] **ระบบส่งออกไฟล์ตารางจัดอันดับ (Export Excel Format):**
  - [x] ออกแบบ API สร้างไฟล์ Excel ตามรูปแบบคอลัมน์ A ถึง N ตามข้อกำหนด:
    * **A (ที่):** ลำดับที่ในการจัดอันดับสุดท้าย (1, 2, 3, ...)
    * **B (เลขที่ประจำตัวสอบ):** เลขที่ประจำตัวสอบที่อ้างอิงจากประกาศรอบแรก
    * **C (คำนำหน้า):** คำนำหน้านามของผู้สมัคร
    * **D (ชื่อสกุล):** ชื่อจริงและนามสกุลของผู้สมัคร
    * **E (กำลังศึกษาโรงเรียน):** ชื่อโรงเรียนเดิมที่กำลังศึกษาในระดับ ม.3
    * **F (คะแนนรวม):** คะแนนสอบรวมรอบแรก (คณิตศาสตร์ + วิทยาศาสตร์)
    * **G (คะแนนคณิต):** คะแนนสอบรายวิชาคณิตศาสตร์รอบแรก
    * **H (คะแนนวิทย์):** คะแนนสอบรายวิชาวิทยาศาสตร์รอบแรก
    * **I (ลำดับรายชื่อตามประกาศ พสวท.):** ลำดับที่ของรายชื่อที่ปรากฏในบัญชีประกาศสอบรอบแรก
    * **J (คณิตศาสตร์):** ผลการเรียนเฉลี่ยสะสมรายวิชาคณิตศาสตร์พื้นฐาน 5 ภาคเรียน (ถ่วงน้ำหนัก)
    * **K (วิทยาศาสตร์):** ผลการเรียนเฉลี่ยสะสมรายวิชาวิทยาศาสตร์พื้นฐาน 5 ภาคเรียน (ถ่วงน้ำหนัก)
    * **L (คณิต + วิทย์):** ผลรวมเฉลี่ยสะสมวิชาคณิตศาสตร์และวิทยาศาสตร์พื้นฐาน 5 ภาคเรียน
    * **M (อังกฤษ):** ผลการเรียนเฉลี่ยสะสมรายวิชาภาษาอังกฤษพื้นฐาน 5 ภาคเรียน (ถ่วงน้ำหนัก)
    * **N (รวมทุกรายวิชา):** ผลการเรียนเฉลี่ยสะสมรวมทุกวิชา 5 ภาคเรียน (GPAX)

## 🔒 6. ความปลอดภัยสิทธิ์ โครงสร้าง และสิทธิ์ฐานข้อมูล (PDPA & Security Hardening)
การรักษาความปลอดภัยของไฟล์อัปโหลด ผลการเรียน ข้อมูลผู้สมัคร และฐานข้อมูลทั้งหมด

- [x] **การจำกัดระดับสิทธิ์จัดเก็บข้อมูล (Restricted Directory Access):**
  - [x] เอกสารแนบและรูปถ่ายผู้สมัครทั้งหมดถูกจัดเก็บใน private uploads directory นอกพื้นที่โฟลเดอร์สาธารณะ (`public/`)
- [x] **Authenticated File Gateway:**
  - [x] การเรียกดูไฟล์ของผู้สมัครต้องผ่าน Next.js Route Handler ที่ตรวจสอบ session, role, และสิทธิ์การเข้าถึงของผู้สมัคร/เจ้าหน้าที่ก่อน stream ไฟล์ออกไป พร้อมตั้งค่า `Cache-Control: private, no-store`
- [ ] **การปรับปรุงสิทธิ์ฐานข้อมูลและความเสถียร (Remaining Features):**
  - [ ] **การแยกสิทธิ์ผู้ใช้งานฐานข้อมูล (Database Least Privilege Separation):** กำหนดการเชื่อมต่อผู้ใช้งานฐานข้อมูลออกเป็น 2 ผู้ใช้: 
    * `Migration User` สำหรับการสร้างและแก้ไขโครงสร้างตาราง (Drizzle Migrations)
    * `Runtime App User` สำหรับ Next.js ใช้งานทั่วไป มีสิทธิ์เฉพาะ SELECT, INSERT, UPDATE และจำกัดสิทธิ์ DELETE
  - [ ] **ระบบสำรองข้อมูลอัตโนมัติแบบเข้ารหัส (Encrypted Automated Backups):** สคริปต์/Cron Job สำหรับการสำรองข้อมูลฐานข้อมูลและไฟล์อัปโหลด รวบรวมและเข้ารหัสไฟล์บีบอัด แล้วส่งไปยัง cloud storage/drive ส่วนตัวของโรงเรียนโดยอัตโนมัติเวลา 02:00 น. ของทุกวัน
